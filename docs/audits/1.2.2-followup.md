# Delta verdict

**One remaining blocker**, in `maintain()`'s modal yield. The other prior findings are fixed or reduced to accepted-scope gaps. I derived this from the code and did not run it.

## Fixed

- **Watcher (#1).** Yield now happens only on `:modal` / `[aria-modal="true"]`. Non-modal `role="dialog"`, popovers, `[inert]` and `pageObstructed` no longer re-lock. The final `viewportLocked() → release(true)` enforces the "never hidden and locked" invariant, and the early return that prevented reacquiring the unlock is gone.
- **Unlock CSS (#2).** When html is visible, only `body{overflow-y:auto}` is applied, so propagation to the viewport is kept and body's used overflow becomes visible. When html is locked, body gets `clip`/`visible`, which is not coerced. Sticky elements and window scrolling survive both lock forms. `viewportLocked()` reads the body's computed `auto` correctly afterwards.
- **Scope (#3, #5, #6).** Every `main` must be clear. The surface observer covers attributes, childList and characterData. Shadow roots, including closed ones, and custom elements refuse. Reversion now reports `presentation-reverted`.
- **Pseudo-element backdrops (#4).** Fixed for `html`/`body` pseudos with both pointer-event modes, and for pointer-receiving backdrops elsewhere.

## Remaining blocker

### Yield has no wake-up for modal exits that produce no observed mutation

Once yielded, `releaseUnlock()` restores the site's lock. `maintain()` only runs again through `changed()`, so unlocking again depends on the next observed mutation batch.

- **Fullscreen.** `:modal` matches fullscreen elements per the HTML spec, so an in-article video or YouTube iframe entering fullscreen triggers a yield when any mutation lands (ad rotators make that near-certain). Exiting fullscreen changes no DOM. The page stays frozen with the wall hidden until some unrelated mutation occurs, and on a quiet page that is indefinitely.
  - Repro on the fixture after commit: add `<video controls>` inside `article`, call `requestFullscreen()`, append any node to `body`, wait 200ms, `exitFullscreen()`, then wheel. `scrollY` stays at 0 and `#surface` stays hidden.
- **`dialog.showModal()` / `close()`.** This includes Esc and `form method=dialog`, which only toggle `open`. Unless the content observer's `attributeFilter` includes `open`, the same state results. The modal test only removes the node, which is a childList change, so it does not cover this path.

**Fix:** while `current` is set, add document-level `close` (capture), `cancel` and `fullscreenchange` listeners that call `changed()`. Add a test for fullscreen enter/exit and for `showModal()` / `close()`.

## Non-blocking residuals

These are fail-safe or within the stated scope.

- **Contained surface exempts `main` from the clarity check.** `contentCandidates` drops any `main` that contains the surface. With a surface portaled into `main` and the story in a blurred inner `div` beside a clear `aside article`, the aside article becomes the only candidate and passes.
- **Descendant suppression is not checked.** `clearContent` walks ancestors only, so `<main><div style="filter:blur(4px)">story</div></main>` passes: probes hit inside `main`. The same applies to a `pointer-events:none` fixed dimmer sibling, or to a pseudo on anything other than `html`/`body`, because hits pass through to content. This is visual only, since interaction is intact, and it falls under "no full visual semantics". The diagnostic will still say `hidden`.
- **The whole-subtree observer releases on benign churn.** Countdown text, animation-driven `style`/`class` writes and `aria-live` updates inside the hidden surface will re-show the wall, and `done` prevents a retry. This is the fail-safe direction, but expect a higher `presentation-reverted` rate on animated walls.
- **SPA route changes that replace `main`** disconnect `content`. `clearContent` then fails, so we `release(true)` and report "reverted". That is truthful enough, but "kept over SPA navigation" holds only for same-DOM route changes.
- **Per-batch cost.** `probeLock()` toggles our attribute and forces style plus layout (`scrollHeight`) on every coalesced batch, even when nothing relevant changed. Computing the desired state before touching attributes would avoid the churn. This is low priority.
- **bfcache Back-navigation test** is still absent.
