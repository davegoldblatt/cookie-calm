I found no new actionable blockers in this delta.

- **The notice check in `src/sourcepoint-us.js:11-12`:** the extra check only makes it more likely that the US adapter takes the frame. It still requires the same HTTPS, `privacy-mgmt.com`, `/us_pm/index.html` and "must be inside an iframe" conditions. `engine.exclusive` calls it fresh each time: in `runNext` (`rule-engine.js:128`) and in both generic fallbacks (`content.js:191,221`). So if a notice URL later shows `.pm-toggle`, `[role=switch]` or `.sp_choice_type_SE`, the old rules and generic fallbacks are shut out from then on. Claiming the frame does not by itself click anything. The adapter still requires exactly one toggle, the opt-out label and a single Save and Close button, and otherwise refuses.
- **Tests:**
  - The notice variant of the 6.5 s refusal test (line 77–78) hits the case you described: a notice URL with an unknown toggle and legacy Reject/Accept buttons. It expects no clicks and no save.
  - The Options → separate manager test (lines 92–100) confirms that a plain notice (no toggle or Save button) is still left to the existing rules, and that the manager loaded next completes `toggle, save`.
  - The route patterns look correct. The notice route with `?is_usnat_notice=true` matches under both older and newer Playwright glob handling of `?`, and the plain `frameURL` route won't catch the query-string URL.

Two minor non-blocking notes:
1. A notice that has an `.sp_choice_type_SE` button but no toggle now counts as the US manager. The adapter would then refuse it and the old rules would skip it. That fails closed and only costs coverage, but it's worth remembering if a real notice uses an SE-type button.
2. Ownership is checked each time a rule is chosen, not while a rule is running. If an old rule has already started on a plain notice and that same document then turns into a manager partway through the run, that run isn't stopped. This is unlikely because the manager loads as a separate navigation (as your test models), and it was already true before this change.
