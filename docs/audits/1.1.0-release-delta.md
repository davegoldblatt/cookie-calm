## Remaining limitations (none block the release)

1. **Some prompts will now stay up that could have closed.** Any in-page link or control target counts, including "Skip to content" links (`href="#main"`) and tab controls. A prompt placed inside that target stays open for the rest of the page. It's the safe direction, but it will cost some dismissals on sites with those links.
2. **A menu button with no target is still unprotected.** If the button has no `aria-controls` or `#href` and the drawer doesn't take focus, it falls under the documented "ambiguous intent" limit. The live menu and search checks passed.
3. **R3 and R4 are unchanged.** A site can focus a prompt's field right after an unrelated click and protect it for the rest of the page, and full scans still stop at 100 candidates. Both only cause missed dismissals.
4. **The two new tests only check that nothing happened.** Test 60 and test 48 don't also show that the extension scanned the page, so they rely on the matching tests that do. That's acceptable.
