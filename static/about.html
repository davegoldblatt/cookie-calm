Cookie Calm

Cookie Calm applies consent choices through the controls on supported websites. It rejects optional cookies by default.

Two choices

Reject optional cookies requests the most restrictive choices supported by the bundled rules. Unknown banners stay visible.

Allow acceptance if needed tries the same rejection flow first. If that fails, it can use a recognized acceptance button. This can allow tracking.

A checkmark means that a banner disappeared after an action. It does not prove that a website honors your choice.

Automatic popup handling

Supported newsletter, subscription, donation, offer, survey, optional registration, app, notification, and chat prompts close or minimize in both cookie modes.

Chat handling covers proactive greetings without a conversation or composer. Playing or previously played media stays available.

Cookie Calm protects recognized user-opened forms and media. Pausing restores elements hidden by its own styles.

Some native close controls save website preferences. Cookie Calm cannot reverse those choices.

Suspicious pages

Clear scam phrases stop all automatic clicks. Password, payment, and wallet signals stop promotional actions and the acceptance fallback. Download prompts stop the acceptance fallback.

Public HTTP pages and internationalized domains cannot use automatic acceptance. Consent frames inherit checks on the parent page.

These local checks can miss scams or stop on legitimate pages. They do not certify websites. Chrome Safe Browsing remains separate.

Coverage and limits

This build bundles 203 rule files from Consent-O-Matic, plus a conservative detector for common cookie buttons. Rules cover many banner variants.

Delayed banners, embedded frames, and shadow DOM can work. Site changes and unusual consent forms can still require a manual choice.

Cookie Calm does not block trackers, delete cookies, undo past consent, or bypass paywalls. It handles supported in-page notification requests. Chrome notification and location permission prompts remain outside its reach.

Chrome protects its settings pages and the Chrome Web Store from extensions. Cookie Calm cannot run there.

The pause control applies to the exact hostname and all frames in that tab. Other subdomains remain separate.

When you pause, Cookie Calm stops new clicks and restores elements hidden by its own styles. The site can still finish a request from an earlier click.

Privacy and permissions

The extension needs website access to find consent forms and promotional prompts and use their controls. Settings stay in local Chrome storage.

Temporary status stays in session storage. It contains a hostname, rule name, action results, and promotion counts for each open tab.

Recent results distinguish closed panels from recorded privacy choices. A Sourcepoint receipt can verify the saved opt-out after its frame closes. Other supported providers currently report closure without receipt proof.

Up to 12 local result records contain fixed codes. An opaque action ID associates delayed receipt evidence with its action. Raw receipt values remain in temporary memory for at most eight seconds.

There is no account, analytics, remote AI, reporting service, or automatic rule download. Page checks stay on your device.

The extension reads page text, consent-control states, and addresses locally. It does not read password or payment-field values.

Read the privacy policy.

Site controls can send the usual consent requests.

The extension does not request access to the Chrome cookies API or browsing history API.
